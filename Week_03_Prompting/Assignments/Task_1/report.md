# RTF
https://praxislibrary.com/learn/rtf.html

RTF was chosen because its role, task, and format sections make it easy to specify exactly what the model should do and return. 

# CRISP
https://praxislibrary.com/learn/crisp.html

CRISP was chosen because it breaks the task into clear steps, from understanding the question to checking the query.

# RISEN
https://praxislibrary.com/learn/risen.html

RISEN was chosen because it clearly defines the role, steps, goal, and limits of the task. This should keep the generated queries focused on the given schema.
