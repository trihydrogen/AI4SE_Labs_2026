# Task 4 report

## Retrieval design

The retrieval script is [`retrieve_chunks.py`](./retrieve_chunks.py). It
loads the JSON index generated by Task 3, embeds the textual task using the
same tokenizer, hashing function, and IDF weights, and computes cosine
similarity with every stored chunk vector.

Results are sorted by descending similarity and the script returns the top
five chunks by default. Each result includes its score, source path, line
range, and source content, so Task 5 can place the selected context directly
into an LLM prompt.

Example:

```bash
python Task_4/retrieve_chunks.py \
  "Implement InventoryLedger.__contains__ for positive stock" \
  --top-k 5
```
